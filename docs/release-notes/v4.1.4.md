# v4.1.4 — Anthropic 工具响应正文修复

本次修订版补齐 v4.1.3 工具调用修复中的 Anthropic 非流式返回问题，并将 DSML 变体的路由回归覆盖到三个端点。

## 修复与行为

- 修复 `/v1/messages` 非流式纯工具响应在返回正确 `tool_use` 的同时，把原始 DSML 标签重新填入文本块的问题。现在检测到工具调用时使用清理后的正文，空正文也保持为空。
- 工具调用前后的普通正文仍会保留；未解析出工具调用时保留原始回答，避免工具清理逻辑误改普通正文。
- 沿用 v4.1.3 共享解析器对全角 DSML 分隔符、`calls` 包装标签和 `string="true"` 参数的兼容能力，无需客户端额外参数。

## 验证与升级

- 新增 9 项应用路由回归：`/v1/chat/completions`、`/v1/messages`、`/v1/responses` 各覆盖流式和非流式；流式上游逐字符提供截图中的全角 DSML 变体，检查工具名、完整参数、工具结束状态，以及纯工具响应不混入原始标签正文。
- 另外验证 Anthropic 非流式的纯工具、正文混合工具和普通回答三种正文选择，并检查思考内容保留。
- 完整后端测试 322 项通过。本轮新增验收使用测试上游及应用 HTTP 路由，不代表重新统计了真实 DeepSeek 的工具调用成功率。
- 服务端、管理接口及 WebUI 包版本统一为 `4.1.4`。更新后重启服务即可。

当前能力范围与 Codex 配置见 [Responses 中文指南](https://github.com/snake-aabb-wtf/deepseek-web2api-free/blob/v4.1.4/docs/responses-api.md)。本发布不包含 HAR、token、cookies 或临时验收账号配置。
