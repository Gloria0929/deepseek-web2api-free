# v4.1.3 — Codex CLI 工具调用解析修复

本次修订版修复模型输出特定 DSML 变体时，工具调用被当作普通文本返回、Codex CLI 收到原始标签而无法执行工具的问题，同时修复工具参数静默丢失。

## 修复与行为

- 兼容全角竖线 `｜` 与半角竖线 `|` 的 DSML 分隔符，支持 `calls`、`tool_call` 和 `tool_calls` 包装标签。
- 修复 `parameter` 带 `string="true"` 等额外属性时参数被跳过的问题；保留属性名大小写兼容性。显式字符串保持字符串类型、前后空白和空串；非字符串参数保留原有类型解析。
- 流式解析等待完整包装标签闭合后再发布整批调用，保留同一分片中的后续正文。兼容标签逐字符到达，避免原始工具标签泄漏为正文。
- CDATA 内的命令文本、全角字符和标签样字符串保持原值，不对整段命令执行字符替换，也不因其中的闭合标签提前结束批次。
- 修改集中于共享 DSML 解析器和流式筛分器，沿用各协议的工具结果转换与校验。顺带消除解析扫描时逐字符复制剩余字符串的开销。

## 验证与升级

- 新增 21 项变体回归测试，覆盖截图报告格式、参数保真、分片边界、整批调用、CDATA、Unicode 偏移和属性名大小写；完整后端测试 313 项通过。
- Python 同步、Python 异步与 JavaScript OpenAI SDK 各 10 组 HTTP 回归通过。
- 真实 Codex CLI 0.145.0 通过全角 `calls` / `string="true"` 变体验收：脚本化上游逐字符发送标签，CLI 实际执行只读文件命令并回传结果，同时通过 `store=false` 和资源释放检查。此结果不代表本次重新统计了真实 DeepSeek 的工具调用成功率。
- 可通过 `python scripts/verify_codex_responses.py --dsml-variant --cli <Codex可执行文件>` 重复变体验收；中英文 Responses 文档已同步说明。
- 服务端、管理接口和 WebUI 包版本统一为 `4.1.3`。更新后重启服务，无需修改客户端工具参数或新增特殊请求字段。

当前支持范围与 Codex 配置见 [Responses 中文指南](https://github.com/snake-aabb-wtf/deepseek-web2api-free/blob/v4.1.3/docs/responses-api.md)。本发布不包含 HAR、token、cookies 或临时验收账号配置。
