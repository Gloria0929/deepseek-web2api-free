# v4.1.1 — 文档与配置说明校正

本次修订版核对并更新中英文文档、维护说明和环境配置注释，使其与 v4.1.0 的 Responses API、多模态输入和现有实现保持一致。对话协议及处理逻辑没有变化。

## 文档修正

- 更新 README 中的 WebUI 架构和目录结构：管理面板源码位于 `webui-new/`，构建产物位于 `webui-new/dist/`；补充 Responses、共享聊天执行和图片处理模块说明。
- 补充 `/v1/responses` 文档入口及标准 SDK 指引，区分 Responses 的快照续聊与聊天补全、Anthropic 的会话缓存机制。
- 澄清 `SESSION_CACHE_TTL=0` 只禁用聊天补全和 Anthropic 的会话缓存复用；完整历史仍可重放，Responses 状态由独立的 `RESPONSES_*` 配置管理。
- 说明图片 JSON 请求体限制同时覆盖聊天补全、Anthropic Messages 和 Responses，区分 Responses 无效字段的 400 与其他接口可能返回的 422。
- 澄清实时验收脚本和 SDK 不额外重试，但代理适配器仍按既有策略处理上游限流和空响应；补充上游并发、重试、会话缓存容量和 API key 数据库路径配置说明。
- 更新 `AGENTS.md` 的当前版本、能力表与图片引用说明，修正 `.env.example` 中 `LOG_FORMAT` 的默认值注释。多模态历史记录保留原有证据，同时链接当前 Responses 文档。

## 升级与验证

- 服务端、管理接口和 WebUI 包元数据版本同步为 `4.1.1`。更新后按常规方式重新启动服务即可；如需重建 WebUI，请在 `webui-new/` 执行 `npm run build`。
- 修订后的当前文档本地链接和用户可运行 Python 示例经过检查；状态、图片与多轮行为通过相关回归测试验证。
- Responses 的能力范围、内存状态限制和使用示例见 [中文文档](https://github.com/snake-aabb-wtf/deepseek-web2api-free/blob/v4.1.1/docs/responses-api.md)。

本发布不包含 HAR、token、cookies 或临时验收账号配置。
