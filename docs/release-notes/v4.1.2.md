# v4.1.2 — Codex CLI Responses 兼容修复

本次修订版修复 Codex CLI 发送缓存、客户端元数据及推理提示时，`/v1/responses` 因额外参数返回 400 的问题。

## 修复与行为

- 新增独立的请求边界兼容模块，校验并消费 `prompt_cache_key`、`client_metadata`、已知 `reasoning.effort` / `reasoning.summary` 和 `text.verbosity` 提示。缓存键和客户端元数据不进入 prompt、诊断日志或响应快照，也不改变调用方身份和会话关联。
- 接收 `include: ["reasoning.encrypted_content"]`。上游不提供加密推理状态，响应省略该字段，不伪造或编码原始思考内容冒充加密状态。
- 思考仍由服务端 `THINKING` 和 `MODEL_ROUTES` 策略决定；不承诺原生 effort、摘要或 verbosity 控制。未知字段、未知提示值和不支持的功能参数仍返回明确的 400 错误。
- 中英文 Responses 指南补充参数限额、Codex CLI 配置及工具边界。当前支持普通扁平 function 工具；Codex 的联网搜索、应用/插件和多代理 namespace 需关闭。

## 验证与升级

- 完整后端回归 292 项通过；Python 同步、Python 异步和 JavaScript OpenAI SDK 各 10 组 HTTP 验收通过。
- Codex CLI 0.145.0 通过流式首轮与真实只读文件工具回合；验证了工具结果重放、`store=false` 及账号/并发资源释放。该验收使用脚本化上游，不代表本次重新验证了真实 DeepSeek 的工具遵从性。
- 新增可选验收脚本 `scripts/verify_codex_responses.py`；独立审查另验证了 72 组畸形参数。
- 服务端、管理接口和 WebUI 包元信息同步为 `4.1.2`。更新后重启服务；无需在客户端额外删除上述提示字段。

支持范围与配置见 [Responses 中文指南](https://github.com/snake-aabb-wtf/deepseek-web2api-free/blob/v4.1.2/docs/responses-api.md)。本发布不包含 HAR、token、cookies 或临时验收账号配置。
