# v4.1.0 — Responses API 与多函数调用

本次版本新增 OpenAI Responses API 兼容子集，支持标准 SDK 的文本、图片、流式输出、函数调用与多轮续聊；同时增强 Python 和 JavaScript 客户端兼容性。已有聊天补全与 Anthropic Messages 接口继续可用。

## Responses API

- 新增 `POST /v1/responses`、`GET /v1/responses/{id}` 和 `DELETE /v1/responses/{id}`，支持标准 OpenAI SDK；无需项目专用请求头或图片参数。
- 支持字符串及消息 Items、`input_text`、`input_image`，静态 JPEG / PNG / WebP 可使用 base64 data URL 或公网 HTTP(S) 地址。
- 流式响应使用具名 Responses SSE 事件，支持文本、推理和函数参数事件，以及标准 SDK 的流式聚合；事件包含稳定的 Item ID、索引和递增序号。
- 通过 `previous_response_id` 续聊；不可变快照支持从同一父响应创建不同分支，顶层 `instructions` 只用于当前请求。
- 历史图片引用绑定调用方、账号和凭证指纹；续聊时复用文件引用并在独立上游会话中重放历史。状态中不保存原始图片或凭证。

```python
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8080/v1", api_key="你的代理 API key")
first = client.responses.create(model="deepseek-chat", input="记住代号 CEDAR-904。")
second = client.responses.create(
    model="deepseek-chat", previous_response_id=first.id, input="我的代号是什么？"
)
print(second.output_text)
```

完整的图片、流式与工具调用示例见 [Responses 中文文档](https://github.com/snake-aabb-wtf/deepseek-web2api-free/blob/v4.1.0/docs/responses-api.md)。

## 函数调用与兼容性

- 接受 Responses 的扁平 function 工具定义、`tool_choice`、`function_call` 和 `function_call_output`；下游通过 `call_id` 关联并执行函数。
- 默认每轮最多一次调用；显式设置标准参数 `parallel_tool_calls=true` 后，每轮最多可返回 64 次调用。多个结果允许乱序回传，须完整提供当前待解决的结果。
- 支持 `strict` 定义检查、缺省或 null 时的 schema 规范化及明确回退；有效定义用于提示词、结果校验与响应回显。严格校验发生在生成后，上游不保证每次生成合格参数。
- 函数通过 DSML 提示词实现；同一解析批次在发出函数 Items 前整体校验，失败返回 HTTP 错误或 `response.failed`，不会保存成功快照。
- 统一请求参数路径、限流、上游失败与流式错误分类；拒绝不受支持的参数，避免静默忽略。

## 验证与诊断

- **269 项 pytest、7 组启动烟测和 3 个端到端场景通过**；独立审查发现的 schema 引用和深度边界问题已修复并复核。
- Python OpenAI SDK 3.39.0 的同步/异步客户端和 JavaScript SDK 7.45.0 各通过 10 组真实回环 HTTP 场景，包括流式聚合、图片续聊、多函数结果、错误、断流和超时恢复。CI 新增必跑的三客户端验收作业。
- 使用更新凭证对真实上游完成 Python 与 JavaScript 验收：文字续聊；首轮只回复 `ACK` 后识别历史图片；追加第二张图片后比较；严格双函数调用与逆序结果回传。最终验收共 14 次聊天请求、4 次图片上传，比较请求携带两张图片引用。
- 新增安全阶段诊断，记录账号等待、图片上传/处理、生成、存储及流式首输出耗时；白名单字段不包含正文、图片、工具数据或凭证。

## 升级与使用边界

1. 升级后重新安装 `requirements.txt`；Windows 用户可使用 `start.bat` 更新依赖。
2. `store=true` 的 Responses 状态只保存在当前进程的有界内存中，默认 TTL 为 1800 秒；重启会丢失，多 worker 不共享。祖先状态过期、删除或回收后，后代可能无法续聊，需要重发完整历史和图片。
3. 续聊固定原账号和凭证指纹；账号暂不可用或凭证改变时，分别返回明确错误。历史会在新上游会话重放，长对话会增加请求量与耗时。
4. 工具参数增量可能在完整 DSML 批次解析后发送；`strict` 是生成后的校验，不是受约束解码保证。`parallel_tool_calls` 默认仍为 false。
5. 暂不支持托管工具、后台任务、Conversations API、WebSocket、加密推理、结构化输出保证、音频/PDF，或显式 `max_output_tokens`、`temperature`、`top_p`。准确视觉 token 和上游账单数据不可得。
6. 公网图片 URL 受实际 DNS/网络与安全地址校验限制；当前环境历史验证曾遇到 fake-IP 被拒绝。真实上游图片验收使用已验证的 base64 data URL。

本发布不包含 HAR、token、cookies 或临时验收账号配置。
